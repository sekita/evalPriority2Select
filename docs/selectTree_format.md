# 出力される選択木（selectTree）の見出し形式

## 1. 全体構成

プログラムの出力は必ず次の3部分からなる。

```text
tableE: evalTable.md, tableP: priorityA.md

# 六角;高効果
...
```

1. 1行目: `tableE: {評価表ファイル名}, tableP: {優先度表ファイル名}`
2. 2行目: 空行
3. 3行目以降: 選択木の見出し

1行目にはディレクトリを含まないファイル名だけを書く。1行目は `#` で始まらないため、見出しとして木のノードにはならない。

## 2. 見出しレベルと木の深さ

`#` の個数が木の深さを表す。

```text
# ルート
## 子
### 孫
#### ひ孫
```

深さに固定上限はなく、必要に応じて `#` を増やす。

## 3. 中間ノード

評価項目でさらに分岐するときは、中間ノードに `六角;` を付ける。

ルートの中間ノード:

```text
# 六角;高効果
```

2階層目以降の中間ノード:

```text
### |◎|六角;導入の早さ
```

一般形は次である。

```text
{'#' * level} |評価値|六角;評価項目
```

実際のファイルでは `{...}` を書くのではなく、その深さの個数の `#` を書く。

## 4. 枝ラベル

ルート以外では、親からそのノードへ至る評価値を `|評価値|` としてノード名の直前へ付ける。

```text
## |◎|六角;低運用費用
### |×|増員
```

`|` の内側には空白を入れない。

## 5. 単一の葉

選択肢が1件に絞れたら、その時点で葉にする。未使用の評価項目が残っていても、それ以上分岐しない。

```text
### |◎|AI導入
```

葉には `六角;` を付けない。

## 6. 複数の選択肢が残る葉

評価項目を使い切っても複数の選択肢が残る場合は、1つの葉に選択肢名を列挙する。

```text
###### |◎|担当部署一覧の整理、\nFAQ整備
```

ここで `\n` は実改行ではなく、バックスラッシュと `n` の2文字である。後段の `heading2diagram.py` などがノード内改行として解釈することを想定した表記である。

## 7. ルートが葉になる場合

評価表のデータ行が1件だけなら次のようになる。

```text
# 選択肢A
```

優先度リストが空で複数候補がある場合は、次のようにルートの葉へ列挙する。

```text
# 選択肢A、\n選択肢B
```

## 8. 分岐値の順序

既知の評価値は次の順で出力する。

```text
◎, 〇, △, ×
```

未知の評価値はこれらの後ろに、評価表全体での初出順に出力する。

## 9. 出力例

`examples/OselTreeA.md` と `examples/OselTreeB.md` は、プログラムが実際に生成する完全な出力例である。どちらも入力ファイル名を示す1行目と空の2行目を含む。
