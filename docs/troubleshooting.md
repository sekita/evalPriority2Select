# エラー・警告と注意事項

## 1. まず確認する項目

入力で問題が出た場合は、次を順に確認する。

1. `#` / `##` の前に空白がないか。
2. 評価表の各選択肢に、評価項目数と同じ個数の `##` があるか。
3. 優先度表の最初にヘッダブロックがあるか。
4. 優先度表の評価項目名が評価表ヘッダに存在するか。
5. 入力文字コードが UTF-8 または Shift_JIS（CP932）か。
6. `|` を項目名や値に含めていないか。

## 2. 主なエラー

| 状況 | 結果 |
| --- | --- |
| 入力ファイルを開けない | エラー、終了コード1 |
| 評価表に見出しがない | エラー |
| 評価表にデータ行がない | エラー |
| 評価表ヘッダに評価項目 `##` がない | エラー |
| 選択肢の評価値が不足 | エラー |
| 優先度表に見出しがない | エラー |
| 順位を整数にできない | エラー |
| 順位ブロックに評価項目 `##` がない | エラー |
| 優先度表の評価項目が評価表にない | エラー |
| UTF-8 / CP932 のどちらでも読めない | エラー |

## 3. 主な警告

| 状況 | 動作 |
| --- | --- |
| `##` が最初の `#` より前にある | その `##` を無視 |
| `###` 以上の見出しが入力にある | その行を無視 |
| 評価項目が重複 | 最初の列を使用 |
| 評価値が列数より多い | 超過分を無視 |
| 1つの順位に `##` が複数 | 最初の項目を使用 |
| 優先度表で同じ評価項目を重複指定 | 後の指定を無視 |
| 評価表の項目が優先度表にない | その項目を分岐に使わない |
| `#` の前に空白がある | 見出しとして無視 |

## 4. 現行仕様上の制限

- UTF-16、EUC-JP などには対応しない。
- 出力は入力文字コードにかかわらず UTF-8（BOM なし）である。
- 出力の先頭2行を省略するオプションはない。
- 全角 `ｘ` / `Ｘ` は `×` の別名として扱わない。
- 名前や評価値中の `|` はエスケープされない。
- 選択肢名の重複は検査しない。
- 順位は整数なら `0` や負数も受け付ける。
